# Mimi Study

> 一个面向个人学习规划、专注和资料沉淀的本地优先单页 Web 应用。

Mimi Study 将待办计划、番茄钟、心流计时、学习资料、艾宾浩斯闪卡、学习搜索和可选 AI 学习助教放在一个适合移动端使用的页面中。项目不依赖构建工具或第三方运行时；下载后可直接在现代浏览器中打开。

## 功能概览

- **学习计划与任务管理**：按周查看任务，新增、编辑、完成或删除学习任务，并统计目标进度。
- **专注计时**：提供番茄倒计时、心流正计时和休息模式，支持预设时长、专注完成记录与全屏翻页时钟。
- **白噪音与本地音频**：内置环境声控制，支持音量调节、本地音频选择与外部音乐入口。
- **学习资料库**：为任务沉淀笔记、文献卡和链接；文献卡可生成并复制 GB/T 7714 引用格式。
- **闪卡复习**：支持每日抽卡、快速创建、AI 草稿和按复习间隔排序的闪卡队列。
- **学习辅助**：包含灵感暂存箱、倒计时、连续学习与经验值、成就、个人资料与主题切换。
- **学习资源搜索**：提供多个学习资源搜索入口，并可将搜索主题保存为资料链接。
- **数据导出与海报**：可导出 JSON 数据备份，并在浏览器支持 Canvas 时生成周报海报和专注凭证图片。
- **可选 AI 学习助教**：支持 OpenAI 兼容接口、Google Gemini、Anthropic Claude、智谱等服务；可将指定格式的回复导入为闪卡。

## 技术栈

本项目仅使用 `index.html` 中实际存在的技术：

| 范畴 | 使用内容 |
| --- | --- |
| 页面结构 | HTML5 |
| 样式与响应式适配 | 原生 CSS、CSS 变量、媒体查询与安全区域适配 |
| 交互逻辑 | 原生 JavaScript（ES5 风格函数与 DOM API） |
| 本地数据 | `localStorage`（键名：`mimi_study_v6`） |
| 浏览器能力 | Web Audio API、Canvas、Clipboard API、Web Share API、Fullscreen API |
| 可选远程能力 | 使用 `fetch` 直连用户配置的 AI 服务接口 |

未使用 React、Vue、Angular、Node.js、npm、Webpack、Vite 或任何包管理依赖。

## 环境要求

- 任意现代浏览器：Chrome、Edge、Firefox、Safari 或移动端浏览器。
- 若要使用 AI 学习助教，需要自行申请对应服务商的 API Key，并确保浏览器或应用壳允许跨域请求。
- 无需安装 Node.js、npm 或其他依赖。

## 安装与运行

### 直接打开

1. 克隆仓库：

   ```bash
   git clone https://github.com/maduenodederick-code/Mimi-study.git
   cd Mimi-study
   ```

2. 用浏览器直接打开 `index.html`。

### 使用本地静态服务器（可选）

部分浏览器对本地文件的权限更严格时，可使用任意静态服务器。例如已安装 Python 时：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 使用说明

1. **计划**：在“计划”页添加学习任务，选择对应日期和预估专注时长。
2. **专注**：在“专注”页选择模式与时长，开始后完成一次专注会更新学习数据。
3. **资料**：为任务添加笔记、文献或链接；文献记录可复制 GB/T 7714 引用。
4. **复习**：通过“每日抽卡”或闪卡列表复习知识点，也可手动新建闪卡。
5. **数据安全**：在偏好设置中导出 JSON 备份。浏览器清理站点数据会清除本地学习记录。
6. **显示与声音**：可在偏好设置切换主题、声音、显示模式与字体大小。

## AI 助教配置

AI 助教默认不会联网。需要使用时，在助教面板中点击“配置”，选择服务商并填写 API Key、模型与接口地址。

- 可选择 OpenAI、Gemini、Claude、智谱以及 OpenAI 兼容的自定义接口。
- 密钥和聊天记录仅保存在当前浏览器的 `localStorage` 中，不会提交到仓库。
- 这是纯前端直连实现，浏览器请求可能受到 CORS、网络环境或服务商安全策略限制。
- 请不要在公共设备上保存 API Key；部署到公开站点时，建议改用受控后端代理后再输入长期密钥。

## 部署

这是一个静态站点，可部署至 GitHub Pages、Netlify、Vercel、Cloudflare Pages 或任意支持静态文件的 Web 服务器。

以 GitHub Pages 为例：

1. 将本仓库推送到 GitHub。
2. 在仓库 **Settings → Pages** 中选择从 `main` 分支根目录部署。
3. 保存后等待 GitHub Pages 提供站点地址。

部署后应用仍使用访问者浏览器中的本地存储；不同设备和浏览器之间不会自动同步数据。

## 常见问题

### 刷新后数据不见了？

数据存放在浏览器 `localStorage`。检查是否清理了站点数据、使用了无痕模式，或更换了浏览器。请定期导出 JSON 备份。

### AI 助教提示请求失败？

确认 API Key、模型名称与接口地址匹配；再检查网络、服务商额度以及浏览器跨域限制。部分服务商不允许从浏览器直接请求。

### 音频或下载功能在手机上不可用？

移动浏览器和 WebView 对自动播放、文件下载与分享能力限制不同。页面会优先使用浏览器或宿主支持的分享和图片预览能力。

### 为什么没有 `npm run dev`？

本项目是无构建步骤的原生静态应用，直接打开 `index.html` 或通过任意静态服务器访问即可。
