# Mimi Study

Mimi Study is an AI smart learning assistant built with Flutter.

## Current foundation

- Soft blush pink and warm cream visual theme
- Five-tab navigation: Home, Plan, AI Assistant, Library, and Profile
- Home dashboard with daily overview, quick actions, and today's plan placeholder
- Starter structure ready for feature development

## Run locally

Install Flutter, then run:

```bash
flutter pub get
flutter run
```

## Development branch

The current starter implementation is on `feature/mimi-study-foundation`.
The original `main` branch is preserved. A backup branch named
`backup/before-app-scaffold` was created before changes.
